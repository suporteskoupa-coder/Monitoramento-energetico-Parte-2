# Histórico

Esta pasta preserva versões antigas, anotações, exercícios e conteúdo único recuperado de
arquivos compactados. Nada aqui deve ser tratado como implementação, dado ou procedimento
oficial sem nova validação.

- `acompanhamento/`: materiais organizados por semanas;
- `aprendizado/`: exercícios básicos e exemplos;
- `anotacoes/`: notas soltas preservadas;
- `firmware/`: protótipos anteriores de bancada;
- `repositorio-compactado/`: versões únicas encontradas no ZIP antigo;
- `configuracao/`: configuração legada apenas para consulta.

Consulte [`../docs/MIGRACAO.md`](../docs/MIGRACAO.md) para os critérios usados.
