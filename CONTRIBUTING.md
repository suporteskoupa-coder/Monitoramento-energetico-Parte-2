# Como contribuir

1. Crie uma branch curta para uma única mudança.
2. Não altere arquivos em `dados/brutos/` nem reescreva o histórico.
3. Para cada campanha, copie `experimentos/_modelo/` e preencha os metadados antes da coleta.
4. Guarde resultados derivados em `dados/processados/` e registre script, regra e campanha.
5. Vincule mudanças de firmware à campanha e ao commit utilizado.
6. Atualize documentação e pendências quando uma decisão for fechada.
7. Abra um pull request para revisão antes de integrar à branch principal.

Conteúdo em `historico/` é somente referência. Novos trabalhos devem usar as áreas atuais.
